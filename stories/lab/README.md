# The Lab (E.L.D.R.I.T.C.H)

Built in Adam's separate "The Lab" project and copied here from its published artifact. The campfire's Lab stump opens this folder.

Two small additions on this side: a "◄ Fireside" link next to the sound button, and `reportTrophy` in `game.js`, which records each ending in the shared `fireside-tales.trophies` key so the campfire trophy log can show it (the "refused" ending counts as Failed). When a newer build comes over from The Lab project, keep those two additions.
